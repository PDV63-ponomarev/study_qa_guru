в командной строке: scoop install allure

pip install allure-pytest



запуск отчета: allure serve путь/allure-results


pycharm:
в modify run configuration
additional arguments: --alluredir=allure-results


VSC:
Launch Visual Studio Code.

Open the Extensions view.

In the Search Extensions in Marketplace field, enter qameta.allure-vscode.

Click on the Allure Support extension, then click Install.

Wait for the installation to complete.


В корне проекта можно создать файл pytest.ini следующего содержания:

[pytest]

addopts =

    --clean-alluredir

    --alluredir=allure-results

в таком случае, параметры запуска будут браться из этого файла,
 и указывать отдельно в команде запуска эти параметры будет не нужно
