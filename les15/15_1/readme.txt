аргументы запуска
pytest

--co   показывает что будет запушено, но не запускает

-----------

-k  дает возможность выбора фильтра, по логическим выражениям
например фильтр по имени или "name1 and/or name2"
"(name1 and name2) or name3"

-----------

-m   выбор по признаку теста, нужны маркры на тесты

@pytest.mark.somemark
def test_smth():
    ...

pytest -m "somemark"
pytest -m "not somemark"

в pyproject.toml нужно зарегестрировать марки
markers = [
    'somemark: Описание'
]

-----------

--markers

показывает список марок исп в pytest и проекте


-----------

--fixtures

показывает фикстуры в проекте


-----------

--setup-plan

покажет информацию о тесте со всеми шагами выполнения


-----------

--duration=10

показывает, после выполнения тестов, 10 самых долгих частей тестов


-----------

-v
выводит более полную инфу о выполненых тестах

-----------

-l
в случае падения теста показывает значения переменных

-----------

в pyproject.toml можно указать ключи с которыми всегда будут выполняться тесты
нужно создать строку addopts="ключи через пробел"

addopts="-l -v -m 'not slow'"

-----------

марки пропуска

@pytest.mark.skip(reason="описание причины скипа")
@pytest.mark.skip
пропускает данный тест

pytestmark = pytest.mark.skip(reason="описание причины скипа")
пропустит все тесты в файле



@pytest.mark.skipif(условие)
если переменная или результат функции соответ скипу, то пропускатеся


@pytest.mark.xfail(reason="не обновляется код")
предупреждающее о падение, не будет ошибки


-----------


параметризация

@pytest.mark.parametrize('параметр')
указываются какие параметры будут передаваться в функцию
если несколько параметров, то тест будет выполняться несколько раз с разными параметрами
