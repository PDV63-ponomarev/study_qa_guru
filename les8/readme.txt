Объектный подход - абстракция
Класс - это абстракция, которая описывает поведение и состояние объекта. Экземпляр - это конкретный объект, который создан на основе класса.

Наследование
Наследование позволяет создавать новые классы на основе уже существующих. Новый класс может расширять функциональность существующего, а так же переопределять его поведение.

Полиморфизм
Полиморфизм позволяет использовать один и тот же интерфейс для разных типов объектов.

Модули и классы

Вопросы для самоконтроля:
Для чего нужен self?
это ссылка на экземпляр класса (объект), который используется для доступа к атрибутам и методам этого объекта внутри класса.

Как используется init() в классе?
def __init__(self, name, age ,items):
    self.name = name

Что такое @classmethod?
это декоратор в Python, который преобразует класс в метод класса (class method).
Такой метод получает первым аргументом не объект (self), а сам класс (cls).

class Date:
    def __init__(self, year, month, day):
        self.year = year
        self.month = month
        self.day = day

    @classmethod
    def from_string(cls, date_string):
        """Создает Date из строки 'YYYY-MM-DD'"""
        year, month, day = map(int, date_string.split('-'))
        return cls(year, month, day)  # cls = Date

Что такое @staticmethod?
это декоратор в Python, который создает статический метод.
Это обычная функция, помещенная в пространство имен класса, но
не получающая автоматически ни self (объект), ни cls (класс) в качестве первого аргумента.

class MyClass:
    @staticmethod
    def greet():
        return "Привет!"

# Вызов из класса
print(MyClass.greet())  # Привет!

# Вызов из объекта
obj = MyClass()
print(obj.greet())      # Привет!


Что такое @property?
позволяет превращать методы класса в атрибуты, доступные для чтения.
Это обеспечивает контроль над доступом к данным

class Person:
    def __init__(self, name):
        self._name = name  # "Приватный" атрибут

    @property
    def name(self):
        """Геттер - вызывается при обращении к obj.name"""
        return self._name.upper()  # Можем модифицировать данные

p = Person("Иван")
print(p.name)  # ИВАН (аутоматически вызывает метод name())


Зачем нужны дата-классы?

Dataclasses — это Pythonic-способ создавать классы для хранения данных,
который стал стандартом де-факто в современном Python.

Дата-классы нужны для:
Уменьшения шаблонного кода — автоматическая генерация методов
Повышения читаемости — явное объявление полей с типами
Типобезопасности — аннотации типов + возможность проверки
Иммутабельности — frozen=True для неизменяемых объектов
Стандартизации — единый подход для DTO и структур данных


Какие типы данных удобно использовать с Enum?

Enum (перечисления) в Python используются для создания именованных констант,
которые делают код более читаемым, безопасным и поддерживаемым

class Status(Enum):
    students = 'student'
    worker = 'worker'

Фиксированный набор именованных констант
Нужна типизация и автодополнение
Требуется безопасность от опечаток
Значения известны на этапе разработки
Нужна итерация по всем возможным значениям
